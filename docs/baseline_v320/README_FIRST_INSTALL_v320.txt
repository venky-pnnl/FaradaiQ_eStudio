FaradaIQ Studio v320

1. Extract FaradaIQ_Studio_v320_package.zip.
2. Run Install_FaradaIQ_Studio_v320.bat.
3. The application installs side-by-side under C:\FaradaIQ\Studio\V320.
4. Default analysis output is C:\Data\ANALYSIS\Faradaiq.

The package is complete. No second installation archive is required.

The installer verifies PACKAGE_MANIFEST_SHA256_v320.txt before bootstrapping the private runtime. If payload verification fails, reinstall from an intact v320 package rather than bypassing the check.
