# FaradaIQ Studio v320

FaradaIQ Studio v320 is a side-by-side release for potential-dependent Mott-Schottky/EIS datasets. It preserves the v318 rule that standard EIS and DRT analysis must remain visible in the summary PowerPoint, and upgrades those figures into consistent potential-resolved overlays.

The summary PowerPoint now includes a Nyquist overlay, Bode magnitude and phase overlays, a DRT overlay, and a DRT potential map with dominant-relaxation tracking in addition to the existing MT-specific capacitance, PZC, Mott-Schottky validity, circuit-fit, residual, and DRT peak-track analysis.

Overlay formatting uses the complete bias-resolved dataset as a light background and highlights a consistent set of representative potentials across Nyquist, Bode, and DRT views. This makes the complete evolution visible without turning the slide into an unreadable 85-entry legend.

Default analysis folder: `C:\Data\ANALYSIS\Faradaiq`

Install target: `C:\FaradaIQ\Studio\V320`

Use `Install_FaradaIQ_Studio_v320.bat` from the extracted complete package.
