# FaradaIQ eStudio v341: 80-function coverage

All functions below have local implementations and user-facing controls. Open **Workbench**, then the indicated area. The desktop **Advanced workbench** button opens the browser with the current source. Multiple instrument handles share one session while retaining source identity and units.

The table follows the original feature numbering. Verification references are in the packaged `tests` directory. They identify targeted analytical and workflow coverage; supported method scope and platform limits remain important. Read [the guide](workbench_guide.md), [science methods](workbench_science_methods.md), [impedance methods](workbench_impedance_methods.md), and [release QA](../QA_v341.md).
