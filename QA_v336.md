# Verification for FaradaIQ eStudio v336

Built from the checksum-verified v335 package. See the [release provenance](docs/provenance_v336.json).

- **GitHub upload.** Local Git remotes exercised uploads against an existing main branch and an empty repository, ZIP manifest verification, executable modes, duplicate tags, and concurrent remote changes. Overlapping changes stopped the upload and remained intact on the remote.
- **Installer order.** Windows launcher contracts and macOS installer fixtures exercised core setup, analysis tool setup, SciLink setup, and one-click launch or no-launch behavior with a synthetic environment.
- **Analysis tools.** DearEIS 5.1.3 installed and imported in a separate Python 3.12 environment on Linux. Official pyDRTtools 0.2 constructed its Qt GUI offscreen with the pinned eStudio dependencies. Confirmed binary wheel downloads for both Intel and Apple Silicon macOS.
- **Scope.** Native Windows and macOS installation and a live GitHub release publish were outside this verification.
