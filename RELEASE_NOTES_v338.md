# FaradaIQ eStudio v338

- The GitHub README opens with the eStudio logo and a link to the styled project website. The styled page includes the eStudio and SciLink logos and the same workflow, detailed methods, Windows and macOS instructions, contributor credits, and NETS acknowledgment.
- The uploader publishes the release and then checks GitHub Pages for the public eStudio repository. With a repository maintainer's GitHub credentials, it enables Pages from `main` and `/docs` when needed. An existing Pages configuration or repository website address is preserved.
- The installer package drops the retired v320 release audit, installers' support scripts, compatibility launcher, and obsoleted release-only tests from the source tree. GitHub's file list still shows the last commit that changed each file.

## Project website

Open the [styled website](https://venky-pnnl.github.io/FaradaiQ_eStudio/) after GitHub finishes deploying it, or open `docs/homepage.html` in the extracted package. If GitHub requires the maintainers to complete Pages setup, use [Settings → Pages](https://github.com/venky-pnnl/FaradaiQ_eStudio/settings/pages) and select **Deploy from a branch → main → /docs → Save**.

See the [workflow guide](docs/workflows.md#install-and-start) and [verification notes](QA_v338.md).
